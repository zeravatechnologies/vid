# Vid web app

The free Vid, in the browser: paste text, see what is hidden. It runs the
**same** Python input layer as the download, via Pyodide (WebAssembly), so the
text you paste never leaves the page — nothing is sent to a server.

## Files
- `index.html` — the page (UI).
- `app.js` — the Pyodide loader and the check (no inline script, so a strict
  Content-Security-Policy can allow it). `?example=<name>` pre-fills one of
  the examples and checks it; `?embed=1` hides the page title and links, for
  embedding on the product page.
- `pkg.js` — Vid's pure-Python input layer bundled as `window.VID_FILES`,
  generated by `build.py`. Regenerate it whenever the input layer changes:

      python3 web/build.py

## How it runs
On load, the page starts Pyodide, writes the files from `pkg.js` into Pyodide's
virtual filesystem under `/pkg/vid/…`, puts `/pkg` on `sys.path`, and imports
`vid.input_layer.analyze`. Each check calls `analyze(text).as_dict()`. Pyodide
itself is loaded from `cdn.jsdelivr.net/pyodide/v0.26.4/`.

## Checked in a real browser
14 Oct 2026, Chromium 155 headless, served over http with the strict
Content-Security-Policy the site uses for it (`script-src 'self'
https://cdn.jsdelivr.net/pyodide/v0.26.4/full/ 'wasm-unsafe-eval'`, the same
for `connect-src`, no `'unsafe-eval'`, no inline script): the engine reaches
"Ready"; Base64, invisible characters, look-alike letters, hidden in JSON and
reversed are each found with the decoded text shown; a plain sentence reports
"Nothing hidden found". To repeat it by hand:

    python3 web/build.py
    python3 -m http.server -d web 8080   # then open http://127.0.0.1:8080/

On zeravatech.ca it lives at /vid-app/ (embedded on /products/vid/), with
the Download Vid and Vid guide links.
